## Featured Projects

### [Equathora](https://github.com/zaimhalili/equathora)
Gamified, AI-powered platform for math competition preparation. Built and maintained solo.

- ~280 curated problems organized as Subject → Topic → Difficulty → Problem
- XP and reputation system, mentorship with a weighted Mentor Score
- LaTeX answer input with MathLive, final-answer validation
- Free, Scholar and Olympiad tiers with Stripe payments

`React` `TypeScript` `PostgreSQL` `Supabase` `Framer Motion` `Stripe`
